## What to build

Establish the documented basis required by the parent specification for publicly reusing the book's tracking metadata. Deliver verifiable evidence and publication-ready attribution/licensing boundaries that the release slice can apply. This is an independent external-evidence prerequisite, not a standalone application layer or a claim that permission already exists.

## Acceptance criteria

- [ ] Examine authoritative public sources and any permission evidence explicitly supplied by the user for the metadata actually needed: titles, placement, XP, and the tracker catalog. Record exact sources, scope, attribution requirements, and material conditions without inventing a license or claiming an unsupported legal conclusion.
- [ ] Establish and document a supported reuse basis sufficient for the agreed public-release prerequisite. If this cannot be established from available evidence, keep this ticket incomplete and public release blocked; a note that evidence is missing is not completion.
- [ ] Prepare clear attribution to RB Whitaker and The C# Player's Guide, an official-book link, and an unofficial/non-affiliated/non-endorsed statement for release documentation and the website.
- [ ] Document original-code MIT licensing separately from book-metadata rights. Do not imply that the application can relicense third-party metadata merely by adding MIT.
- [ ] Keep exercise instructions, substantial passages, and solution code outside the application. No author contact, outgoing message, or public application deployment is authorized by this ticket without separate explicit authorization.
- [ ] Make the evidence and conditions independently reviewable so the release ticket can verify satisfaction without relying on conversation memory. Local implementation can continue while this prerequisite remains open.
